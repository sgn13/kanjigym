# KanjiGym

KanjiGym is an interactive platform for learning JLPT kanji through quizzes, vocabulary, grammar, and reading exercises.

## Features

- JLPT N5–N1 Kanji
- Interactive quizzes
- Vocabulary practice
- Grammar exercises
- Progress tracking
- English & Japanese support

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- next-intl
- Vercel

## Local Development

```bash
npm install
npm run dev
```
